# HANA TCG — Flavor Text Guide v0.12

Flavor text is the memorable in-world line that sits beside the mechanical rules.

It should make a cheap common feel authored.

## Goals

A good HANA flavor line should do at least one:
- reveal character
- reveal relationship
- reveal the city
- create a recurring phrase/object
- imply a story outside the frame
- make the player smile
- hurt a little on reread

## Default length
Aim for 4–16 words.
Longer is allowed when the rhythm earns it.

## Voice modes

### Character line
Example:
> Sunrise means I win. — Le

### Close narrator
Example:
> Courage usually arrives before the plan.

### Object / place memory
Example:
> Some objects remember the hands that made them.

### Comic relief
Example:
> Prototype 17. We do not discuss 16.

## Do not
- explain the card's mechanics again
- write generic epic-fantasy filler
- use motivational-poster language
- copy a real quote because it sounds smart
- imitate a living writer's signature prose style

## Recurring language

Use repetition intentionally across a season:
- sunrise
- rain
- rooftop
- promise
- looking / looking away
- maps / routes
- masks
- thread
- ordinary objects gaining emotional weight

A repeated phrase should change meaning when the story changes.

## Real-world quotations

Default: original HANA writing.

A real quote requires:
1. verified wording
2. verified source
3. rights/context review
4. attribution
5. a reason stronger than "it sounds cool"

Living-person quotations are never used casually.
