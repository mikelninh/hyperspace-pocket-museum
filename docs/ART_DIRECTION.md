# Art direction

## Locked direction

**Tiny world / hero art + clean collection UI + story-card sharing.**

The object should be desirable before the user reads the label.

### Hero art
Inspired by miniature 2.5D pixel dioramas:
- one mineral as the unmistakable hero
- one storytelling motif per wonder
- restrained props
- strong silhouette
- readable at phone size

### EARTH_001 motifs
- Obsidian — volcanic heat / ancient mirror
- Labradorite — hidden aurora / compass
- Amethyst — twilight garden
- Malachite — overgrown green ruin
- Pyrite — miner lantern / prospecting
- Opal — luminous spring / rainbow light
- Bismuth — impossible geometry / curiosity
- Meteorite — stargazer camp / cosmic arrival

### UI roles
1. **Hero art:** emotional discovery
2. **Collection grid:** fast recognition and ownership
3. **Share card:** one beautiful image + one memorable line

### Quality gate
For every wonder:
- would I want the image as a sticker?
- does the reveal have its own personality?
- can I repeat the science fact tomorrow?
- is folklore clearly separated from evidence?
- do I want to discover the next object?
